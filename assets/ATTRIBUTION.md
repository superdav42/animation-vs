# Asset attribution

The game currently contains no third-party art, music, fonts, or sound effects.

- Interface, arena scenery, characters, vehicles, enemies, weapons, particles, and ability effects are drawn procedurally by the project's GDScript code.
- `icon.svg` was created for this repository and is not sourced from an external asset pack.

When adding external assets, record the file, author, source page, licence, and any modifications here. Prefer CC0 or CC BY material so downstream open-source users can redistribute and adapt the complete game.
